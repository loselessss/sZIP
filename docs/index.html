sZIP 개인정보처리방침

게시자: 신상규 · 시행일: 2026년 9월 23일

sZIP은 Windows에서 압축 파일을 만들고 풀며, 사용자가 설정한 폴더의 압축 파일을 자동으로 풀 수 있는 앱입니다. 이 방침은 sZIP 앱이 다루는 정보에 적용됩니다.

파일 및 설정

sZIP은 사용자가 선택한 파일과 폴더, 그리고 자동 압축 해제를 위해 지정한 폴더에 기기 내에서 접근합니다. 압축 파일의 내용과 암호는 sZIP 개발자의 서버로 전송하지 않습니다. 언어, 감시 폴더, 자동 해제 옵션 등의 설정은 기기에 저장됩니다.

기기 내 기록

앱은 문제 진단을 위한 기록을 기기에 저장할 수 있습니다. 자동 압축 해제 기록에는 처리 시간, 결과, 압축 파일과 출력 폴더의 경로, 오류 내용, 원본 삭제 여부가 포함될 수 있습니다. 이 기록은 자동 전송되지 않으며, 사용자가 기기에서 삭제하거나 지원 요청 시 직접 제공할 수 있습니다. 진단 로그는 크기에 따라 순환 보관되고, 자동 해제 기록은 사용자가 삭제할 때까지 남을 수 있습니다.

업데이트 및 외부 서비스

일반 설치(EXE) 버전은 새 버전을 확인하거나 다운로드할 때 GitHub에 접속합니다. 이 요청을 처리하는 과정에서 GitHub가 IP 주소 등 접속 정보를 받을 수 있으며, 해당 정보에는 GitHub 개인정보처리방침이 적용됩니다. Microsoft Store 버전의 업데이트는 Microsoft Store에서 관리하며, 관련 정보에는 Microsoft 개인정보처리방침이 적용됩니다.

공유 및 선택권

sZIP은 광고나 분석 서비스를 사용하지 않으며, 사용자의 파일이나 앱 사용 기록을 판매하지 않습니다. 자동 압축 해제는 앱에서 끌 수 있고 감시 폴더를 변경할 수 있습니다. 로컬 설정과 기록을 삭제하려면 기기의 sZIP 앱 데이터에서 해당 파일을 삭제할 수 있습니다. 문의나 삭제 방법 안내가 필요하면 sZIP GitHub 이슈로 연락해 주세요. 공개 이슈에는 민감한 파일 내용이나 개인정보를 올리지 마세요.

sZIP Privacy Policy

Publisher: 신상규 · Effective date: September 23, 2026

sZIP creates and extracts archives on Windows. It can also automatically extract archives from a folder selected by the user. This policy describes information handled by the sZIP app.

Files and settings

sZIP accesses files and folders selected by the user, including a folder selected for automatic extraction, on the device. Archive contents and passwords are not sent to the sZIP developer's servers. Language, watched folder, and automatic extraction preferences are stored on the device.

Local records

The app may store diagnostic records on the device. Automatic extraction records may contain the time and result, archive and output folder paths, error details, and whether the original archive was deleted. These records are not uploaded automatically. Users can delete them on the device or choose to provide them when asking for support. Diagnostic logs rotate by size; automatic extraction records may remain until deleted by the user.

Updates and third parties

The standalone installer (EXE) version contacts GitHub to check for or download updates. GitHub may receive connection information such as an IP address when processing these requests; see the GitHub Privacy Statement. Updates for the Microsoft Store version are managed by Microsoft Store; see the Microsoft Privacy Statement.

Sharing and choices

sZIP does not use advertising or analytics services and does not sell user files or app usage records. Users can turn off automatic extraction or change the watched folder in the app. Local settings and records can be removed from the sZIP app data on the device. For questions or help deleting local data, contact us through sZIP GitHub Issues. Do not post sensitive file contents or personal information in a public issue.

Changes

If this policy changes, its content and effective date will be updated on this page.
