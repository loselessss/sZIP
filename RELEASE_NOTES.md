# sZIP 1.10.2 Release Notes (2026-10-07)

## Changes

- Retry failed, skipped, or cancelled extractions from automatic extraction history. Enter a password when required.
- Open output folders directly from history.
- Long paths in history are shortened to fit. Hover to see the full path.

## 1.10.0 Highlights

- Compression progress shows item count, processed size, speed, elapsed time, and estimated remaining time.
- Large 7Z files report progress continuously while each file is processed.

## Known Issues

- In the EXE edition, sZIP does not appear in the Windows 11 primary context menu. Use **Show more options** to access the sZIP menu.
