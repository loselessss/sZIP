# sZIP

[English](README.md)

sZIP은 Windows용 가벼운 압축·해제 프로그램입니다. 파일 압축과 해제, 자동 압축 해제, 탐색기 연동을 한곳에서 간편하게 사용할 수 있습니다.

Windows 10과 11에서 실행되며 한국어와 영어를 지원합니다.

## 주요 기능

- 파일과 폴더를 ZIP 또는 7Z로 압축
- ZIP, 7Z, RAR, TAR, GZ, TGZ/TAR.GZ 압축 파일 열기 및 해제
- 압축 파일에서 선택한 파일과 폴더만 원래 경로를 유지해 해제
- 암호화된 압축 파일의 암호 입력과 진행 중인 작업 취소
- 하위 폴더와 빈 폴더 보존, 기존 결과물을 덮어쓰지 않는 출력 이름 생성
- 처리 속도, 처리량, 남은 시간을 보여주는 작업 진행 상태

## 압축 해제 방식

- **그냥 풀기**는 선택한 위치에 압축 파일의 내용을 바로 풉니다.
- **알아서 풀기**는 최상위 폴더가 하나면 그대로 유지하고, 여러 파일이 섞여 있으면 압축 파일 이름의 폴더 안에 정리합니다.
- **선택 풀기**는 압축 파일 목록에서 선택한 항목만 풉니다.

## 자동 압축 해제

sZIP은 지정한 폴더와 그 하위 폴더에서 새로 내려받은 압축 파일을 감시할 수 있습니다. 설정한 용량 이하의 파일은 다운로드가 끝난 뒤 자동으로 압축 해제됩니다.

메인 리본에서 자동 압축 해제를 켜거나 끌 수 있습니다. 설정에서는 감시 폴더와 최대 용량을 지정하고, 작업 성공 후 원본 압축 파일을 삭제할지 선택할 수 있습니다. 감사 목록에서는 자동 작업의 성공 및 실패 기록을 확인할 수 있습니다.

## Windows 탐색기 연동

탐색기 메뉴에서 파일 압축, 그냥 풀기, 알아서 풀기를 바로 실행할 수 있습니다. 여러 파일을 한 번에 압축하거나 지원되는 압축 파일 형식을 sZIP에 연결할 수도 있습니다.

메인 창을 닫아도 sZIP은 시스템 트레이에서 계속 실행됩니다. 트레이 메뉴에서 창을 다시 열거나 업데이트를 확인하고 프로그램을 완전히 종료할 수 있습니다.

## 설치

[GitHub Releases](https://github.com/loselessss/sZIP/releases/latest)에서 설치 파일을 내려받으세요. 현재 사용자 영역에 설치되므로 일반적으로 관리자 권한이 필요하지 않습니다. 설치하지 않고 사용하는 포터블 ZIP도 함께 제공합니다.

설치 과정에서 바탕 화면 바로가기, Windows 로그인 시 실행, 탐색기 메뉴, 지원 압축 파일 연결을 선택할 수 있습니다.

## 언어와 업데이트

설정에서 **Windows 언어 사용**, **한국어**, **English** 중 하나를 선택할 수 있습니다. 업데이트 내용도 선택한 언어로 표시됩니다.

sZIP은 GitHub Releases에서 새 버전을 확인하며 설치 파일의 크기와 SHA-256 값을 확인한 뒤 설치를 시작합니다. 업데이트는 나중에 설치하거나 버전별로 건너뛸 수 있습니다.
